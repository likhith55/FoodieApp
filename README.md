# Foodie

Foodie is a recipe discovery and sharing app built with Expo and React Native. Browse recipes, save favourites, and add your own dishes.

## Features

- Browse recipes by category and search by name
- View ingredients, preparation details, and cooking steps
- Save and remove favourite recipes
- Create, edit, and delete your own recipes
- Add a recipe photo from your device
- Run on Android, iOS, and web

## Requirements

- Node.js 22.13 or newer
- npm
- Expo Go for testing on a physical phone

## Getting started

Clone the repository and install dependencies:

```bash
git clone https://github.com/likhith55/FoodieApp.git
cd FoodieApp
npm ci
```

Start the Expo development server:

```bash
npm start
```

To open the web version:

```bash
npm run web
```

To test on a phone, install Expo Go, connect the phone and computer to the same Wi-Fi network, then scan the QR code shown by Expo.

## Tech stack

- React Native
- Expo
- React Navigation
- Expo Image Picker
